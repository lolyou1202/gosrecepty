Группа чипсов

app-chip-group — одиночный и множественный выбор, readonly, disabled, программное управление через value.

Одиночный выбор — multiple=false

Значение: {{ singleValue() ?? '—' }}

Множественный выбор — multiple=true

Выбрано: {{ selectedLabels() || '—' }}

Вариант outside — обводка снаружи

Readonly — только просмотр

Disabled — взаимодействие заблокировано

Программное управление — через value
